# AutoPark 建模与算法说明

本文档描述 AutoPark v1.1 的系统建模与算法设计。所有量使用 SI 单位（米、弧度、秒），
世界坐标系 x 向东、y 向北，航向角 θ 自 x 轴逆时针为正。

```text
             ┌──────────── 规划（Web Worker）────────────┐
 环境模型 ──▶ ① 栅格/距离场 ─▶ ② 目标位姿 ─▶ ③ 启发函数 ─▶ ④ Hybrid A* ─▶ ⑤ 平滑 ─▶ ⑥ 速度规划
                                                                               │ 轨迹
             ┌──────────── 闭环仿真（50 Hz）──────────────┐                     ▼
 传感器 ◀── 车辆运动学 ◀── 执行器动力学 ◀── ⑦ 控制器（横向 + 纵向）◀──────────────┘
```

## 1. 车辆模型 `src/model/vehicle.js`

### 1.1 几何参数（C 级轿车）

| 参数 | 值 | 参数 | 值 |
|---|---|---|---|
| 车长 × 车宽 | 4.70 × 1.85 m | 轴距 L | 2.80 m |
| 前悬 / 后悬 | 0.95 / 0.95 m | 轮距 | 1.58 m |
| 最大前轮转角 δ_max | 36° | 转向传动比 | 15.5 |
| 最小转弯半径（后轴） | L / tan δ_max = 3.85 m | 外廓扫掠半径 | 6.07 m |
| 转向速率上限 | 40 °/s | 速度上限 前进/倒车 | 2.0 / 1.2 m/s |

### 1.2 运动学自行车模型

参考点取**后轴中心**（此点速度方向与车身方向一致，模型最简洁）：

```
ẋ = v·cos θ      ẏ = v·sin θ      θ̇ = v·tan δ / L
```

在恒定 (v, δ) 下该方程有闭式解（圆弧），`propagatePose()` 用精确圆弧积分而非欧拉法：

```
R = L / tan δ,   Δθ = Δs / R
x' = x + R·(sin(θ+Δθ) − sin θ),   y' = y + R·(cos θ − cos(θ+Δθ))
```

**规划器的运动基元与仿真器调用的是同一个函数**，保证“规划用的模型”与“被控对象”一致。

### 1.3 执行器动力学

真实车辆的转向机与动力系统不能瞬时响应，模型加入一阶惯性与限幅：

```
δ̇ = sat((δ_cmd − δ) / τ_δ, ±δ̇_max),   |δ| ≤ δ_max,   τ_δ = 0.12 s
v̇ = sat((v_cmd − v) / τ_v, a_max | b_max),            τ_v = 0.25 s
```

### 1.4 阿克曼转向几何

自行车模型的等效转角 δ 对应左右前轮的不同实际转角（渲染车轮时使用）：

```
δ_in = atan(L / (R − T/2)),   δ_out = atan(L / (R + T/2))
```

### 1.5 超声波雷达模型 `src/perception/ultrasonic.js`

12 路探头：前后各 4 个 UPA（0.15–2.5 m，FOV 60°），侧向 4 个 APA（0.3–4.5 m，FOV 30°）。
每个探头在视场内发射 7 条射线与障碍物多边形求交，取最近回波，可选高斯噪声。
运动方向上的探头距离 < 0.1 m 时触发 AEB 紧急制动。

## 2. 环境模型

### 2.1 停车场 `src/model/parkingLot.js`

50 m × 30.6 m 地下停车场：两排各 12 个垂直车位（2.5 × 5.3 m，国标尺寸），6.5 m 主通道；
6.0 m 支路两侧各 4 个侧方车位（N 排 6.2 m 较紧，S 排 7.0 m）；绿化隔离带与结构立柱。
社会车辆从 4 种车型中随机抽取，并带有停放姿态扰动（横向 ±12 cm、偏航 ±2°）——真实停车场中
相邻车辆不会恰好停在车位中心。所有随机量使用可复现种子。

### 2.2 占据栅格与欧氏距离场 `src/model/gridMap.js`

- 0.2 m 分辨率光栅化障碍物多边形；地图边界视为障碍。
- Felzenszwalb–Huttenlocher 可分离平方距离变换，O(N) 求每个栅格到最近障碍的距离 d(p)。

### 2.3 碰撞检测 `src/planning/collision.js`

车身外廓为带安全裕度 m 的有向矩形，三级流水线：

1. **距离场快速通道**：若 d(车身中心) > 外接圆半径 + 分辨率 ⇒ 一定无碰撞（大多数查询在此结束）；
2. **空间哈希粗筛**：2.5 m 哈希格，只取外接圆覆盖范围内的障碍物；
3. **SAT 精检**：分离轴定理判定两个凸多边形是否相交。

## 3. 目标位姿 `src/planning/goal.js`

| 车位 | 方式 | 目标航向 | 后轴位置 |
|---|---|---|---|
| 垂直 | 倒车入库 | θ_in + π（车头朝外） | 开口沿内向 D − c − l_rear |
| 垂直 | 车头入库 | θ_in | 开口沿内向 D − c − l_front − L |
| 侧方 | — | 道路通行方向（靠右） | 车身中心与车位中心重合 |

其中 D 为车位深度，c = 0.35 m 为与底线的间隙。垂直车位额外设置**预目标**
p_pre = p_goal − dir·1.0 m·(cos θ, sin θ)：搜索到预目标，再追加 1 m 直线入库段，
保证车辆在停车前航向误差已收敛。

## 4. Hybrid A* 路径搜索 `src/planning/hybridAStar.js`

### 4.1 状态与离散化

节点保存**连续**位姿 (x, y, θ)；仅用 0.4 m × 0.4 m × 5°（72 个航向桶）的离散栅格做判重与闭集。

### 4.2 运动基元

{前进, 倒车} × 5 个前轮转角 {−δ, −δ/2, 0, δ/2, δ} = 10 条长 0.9 m 的圆弧，每 0.225 m 做一次碰撞检测。
**规划只使用 88% 的最大转角**（`steerUsage`），为跟踪控制器预留纠偏余量——若规划路径本身就是满舵，
控制器一旦出现误差将无力修正，这是实测中侧方停车失败的根因。

### 4.3 代价函数

```
g' = g + l·(1 | w_rev) + w_gear·[换挡] + w_δ·|δ|/δ_max·l + w_Δδ·|Δδ|/δ_max
w_rev = 1.6,  w_gear = 4.0,  w_δ = 0.25,  w_Δδ = 0.5
```

### 4.4 启发函数

```
h(n) = ε · max( h_RS(n), h_2D(n) ),   ε = 1.2
```

- **h_RS**：无障碍 Reeds-Shepp 最短路径长度（非完整约束），只在距目标 22 m 内计算以节省时间；
- **h_2D**：从目标出发的 8 邻域 Dijkstra（完整约束 + 障碍物），可通行条件为 d(p) ≥ W/2 − 0.25。

两者互补：前者理解“掉头需要空间”，后者理解“这条路被堵住了”。

### 4.5 解析扩展（Analytic Expansion）

节点距目标 < 18 m 时，每 ⌊d/2⌋ 次迭代尝试一次 RS 直连：求出全部 RS 候选，按与搜索相同的代价模型
排序，依次检测最多 8 条，第一条无碰撞者即为路径末段。界面上红色虚线是失败尝试（× 为碰撞点）。

### 4.6 Reeds-Shepp 曲线 `src/planning/reedsShepp.js`

实现 Reeds & Shepp (1990) 的全部 48 种路径词（CSC、CCC、CCCC、CCSC、CCSCC 及时间翻转、镜像、
反向变换），另提供只计算长度的快速版本供启发函数调用。单元测试验证随机 500 组位姿下所有候选
路径终点误差 < 1e-6，并验证对称性与三角不等式。

## 5. 路径平滑 `src/planning/smoother.js`

按挡位（换挡点）分段，每段 0.2 m 重采样后做梯度下降：

```
J = w_s·Σ‖x_{i−1} − 2x_i + x_{i+1}‖² + w_d·Σ‖x_i − x_i⁰‖²
```

- 首尾各 2 点固定，平滑权重在两端 6 个点内线性渐入（避免端部扭折）；
- 平滑后逐点做**全车身碰撞检测**与**曲率校验**（三点 Menger 曲率），失败则平滑权重 ×0.4 重试，
  最终可回退到原始路径——平滑永远不会让路径变得不安全。

## 6. 速度规划 `src/planning/speedProfile.js`

每段起止速度为 0（换挡需停车）。速度上限：

```
v_max(s) = min( v_gear,
                √(a_lat / |κ|),                    横向加速度
                v_gear·(1 − 0.55·|κ|/κ_max),       曲率减速
                0.6·δ̇_max / |dδ/ds|,               转向速率（可低至 0.06 m/s）
                0.25 + 1.2·d_obs )                 障碍物距离
```

上限曲线先做 1.2 m 窗口的滑动最小值滤波消除锯齿，再做前向（加速度）/后向（减速度）扫描。

## 7. 轨迹跟踪控制 `src/control/controllers.js`

### 7.1 横向：后轮反馈（默认）

在“运动坐标系”中设计（倒车时航向 +π，误差不变）。取李雅普诺夫函数
V = k_y·e_y²/2 + e_ψ²/2，令

```
κ = κ_r·cos e_ψ / (1 − κ_r·e_y) − k_ψ·e_ψ − k_y·e_y·sin(e_ψ)/e_ψ
δ = atan(L · dir · κ),   k_ψ = 1.6,  k_y = 0.9
```

可得 V̇ = −k_ψ·|v|·e_ψ² ≤ 0。

### 7.2 横向：纯跟踪

```
L_d = clamp(1.0 + 0.6·|v|, 1.0, 2.6),   κ = 2·sin α / L_d,   δ = dir · atan(L·κ)
```

α 为前视点在运动坐标系中的方位角；前视点超出段末端时沿末端切线延长，保证末端收敛。

### 7.3 纵向

```
v_cmd = dir · min( v_ref(s + 0.3), √(2 · 0.6·b_max · (s_remain − 0.02)) )
```

剩余距离 < 3 cm 且车速 < 0.02 m/s 时判定到达段末：进入 SHIFT 状态停顿 0.8 s，
期间转向机预先打到下一段起点转角（原地转向）。
